Official engineering portfolio and systems showcase for **Moses Thomas** (**Moses Naantagam Thomas**, known professionally as **Xheen** / **Xheen Zhyfer**) — [https://xheen.tech](https://xheen.tech).

Senior Full Stack Systems Engineer & Applied Data Scientist specializing in high-concurrency web platforms, autonomous AI agents, enterprise RAG pipelines, and operational data intelligence.

## Technical Architecture

- **Framework**: TanStack Start (SSR / Edge Ready), React 19, TypeScript
- **Styling**: Tailwind CSS v4, Instrument Sans & Instrument Serif typography
- **Database & State**: PostgreSQL, Neon Serverless, PGLite (embedded WASM), TanStack Query
- **AI / RAG**: Google Gemini API, Supabase vector embeddings
- **Deployment**: Nitro engine with Vercel preset (`vercel.json`)
- **Optimization**: Complete Schema.org JSON-LD (Person, ProfilePage, WebSite, FAQPage), OpenGraph, Twitter Cards, `llms.txt` Generative Engine Optimization (GEO)

## Scripts

```bash
npm install     # Install dependencies
npm run dev     # Run local development server (port 8080)
npm run build   # Production build with Vercel Nitro preset & migration runner
npm test        # Run test suites
npm run typecheck # Run TypeScript verification
```
